# دار الخط العربي — نسخة الموقع الكاملة

هذه نسخة Full-Stack: لوحة مدرس محمية بكلمة مرور، والكورسات والفيديوهات محفوظة على الخادم ليصل إليها الطلاب من أي جهاز.

## تشغيل
npm install
ADMIN_PASSWORD='ضع_باسورد_المدرس_هنا' npm start
ثم افتح http://localhost:3000

على استضافة Node.js: ارفع المشروع وشغّل نفس الأمر، واضبط ADMIN_PASSWORD ويفضل SESSION_KEY. لا تستخدم الباسورد الافتراضي في الإنتاج.
